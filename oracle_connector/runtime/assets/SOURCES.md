# Anatomy asset sources

All bundled anatomy data and skin textures are MakeHuman system assets under CC0 1.0.
No MakeHuman executable source code is included.

- Source base: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/3dobjs/base.obj
- Adult masculine morph: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/targets/macrodetails/caucasian-male-young.target
- Adult feminine morph: https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/targets/macrodetails/caucasian-female-young.target
- Core data reuse statement: https://static.makehumancommunity.org/mpfb/faq/build_other_chargen.html
- License classification: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md
- Texture pack and explicit per-asset CC0 list: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- Original archive: https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip
- `male-skin.png`: original archive entry `skins/young_caucasian_male/young_lightskinned_male_diffuse.png`.
- `female-skin.png`: original archive entry `skins/young_caucasian_female/young_lightskinned_female_diffuse.png`.

`anatomy.json.gz` contains the retained head and hands, original UV coordinates and adult
landmarks. It is generated by `scripts/build-anatomy-assets.py` from the base mesh and
these two targets, normalized to 1.8 m with Blender Z up. The runtime interpolates the
two adult forms and fits hands and headwear to the selected pose. These are generic
adult base forms, not a reconstruction of an individual. Wardrobe geometry remains
procedural. The original skin PNGs are unmodified here; runtime tint and eye-atlas
patches are baked into the exported GLB. No network access is needed in Blender.
