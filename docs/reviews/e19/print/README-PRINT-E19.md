# E19 — kandydat konstrukcyjny 200 mm

To osobna kopia do oceny produkcyjnej. Plik wizualny i tekstury pozostają oddzielne. Zakładana wysokość 200 mm obejmuje podstawę; klient nie zatwierdził jeszcze wymiaru zamówienia.

Zamknięto otwory konstrukcyjne sukni, szyi i rękawów. Cienkie włókna wizualne pominięto, pozostawiając większe pasma. Po scaleniu objętościowym zachowano zewnętrzne fragmenty, wykonano 316 lokalnych podpór oraz 89 mostków powierzchni. Usunięto łącznie 4 małe powłoki, dla których każdy wierzchołek przeszedł trzy testy promieni potwierdzające położenie wewnątrz głównej powłoki. Nie usunięto zewnętrznych części anatomicznych.

Końcowy STL: **2 120 444 trójkąty, 1 połączona składowa**. Audyt wykazał 0 otwartych krawędzi, 0 krawędzi niemanifold, 0 błędów orientacji i0 zdegenerowanych trójkątów. Wymiary: **128,704 ×83, 053 ×200, 000 mm**. Dodatnia objętość algebraiczna siatki wynosi 190430,95 mm³; nie jest potwierdzeniem zajętej objętości materiału ani wydruku z 100% wypełnieniem.

Skompresowany GLB podglądowy ponownie zaimportowano i sprawdzono. Domyślna kwantyzacja Draco pogarszała mikrotrójkąty; odrzucono ją. Końcowy eksport z 30-bitową kwantyzacją pozycji przechodzi te same kontrole topologii. Rendery powstały z tego ponownie zaimportowanego GLB.

## Wynik oględzin renderów

Kopia drukarska nadal ma poszarpane włosy, uproszczone uzębienie i zbyt mało czytelne rysy twarzy. Podstawa styka się z najniższymi elementami źródła, w tym palcami; nie potwierdzono stabilnego bezpośredniego podparcia tułowia / sukni. **Ocena wizualna kopii drukarskiej: odrzucona do sprzedaży.** Jest to materiał do dalszej naprawy konstrukcyjnej, nie gotowy produkt.

## Nadal wymagane przed sprzedażą produktu fizycznego

- Kontrola samoprzecięć, minimalnej grubości i wytrzymałości mostków oraz włosów.
- Profil konkretnej maszyny, materiału, podpór, orientacji i wynik slicera lub ścieżek narzędzia.
- Akceptacja wymiaru przez klienta i próbka fizyczna.
- W przypadku kamienia: kwalifikacja obróbki i dostępu narzędzia. Grawerowanie laserowe powierzchni kamienia nie jest równoważne wykonaniu dowolnej pełnej rzeźby 3D; pełny kształt wymaga odpowiedniego procesu, np. frezowania.
